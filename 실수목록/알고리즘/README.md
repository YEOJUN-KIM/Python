# 실수목록 · 알고리즘 유형별 목차

알고리즘 문제에서 틀렸거나 다시 헷갈릴 만한 내용을 문제 유형별로 기록한다.
새 기록은 문제 이름보다 **실수한 해결 방식의 핵심 유형**을 기준으로 분류한다.

## 유형별 기록

| 유형 | 현재 기록 |
| --- | --- |
| [해시](./해시.md) | 영어 끝말잇기, 오픈채팅방 |
| [완전탐색과 조합](./완전탐색과_조합.md) | 소수 만들기 |
| [구현과 배열](./구현과_배열.md) | 바탕화면 정리 |
| [스택과 큐](./스택과_큐.md) | 올바른 괄호 |
| [힙](./힙.md) | 아직 없음 |

## 분류 기준

- 중복 확인, 빠른 조회, 키와 값 관리가 핵심이면 **해시**
- 모든 경우 탐색, 순열·조합이 핵심이면 **완전탐색과 조합**
- 좌표, 인덱스, 이차원 배열 처리가 핵심이면 **구현과 배열**
- 최근에 넣은 값을 먼저 꺼내거나 순서대로 처리하면 **스택과 큐**
- 최솟값·최댓값을 반복해서 빠르게 꺼내야 하면 **힙**
- 여러 유형이 섞이면 실제로 실수한 부분과 가장 직접적인 유형에 기록
