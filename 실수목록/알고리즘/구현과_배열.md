## ❌ 바탕화면 정리 — 문자열 순회와 우측 아래 좌표

- 문제: [바탕화면 정리](../../파이썬_문제풀이/알고리즘/구현과_배열/바탕화면_정리.py) — 모든 파일(`#`)을 포함하는 가장 작은 드래그 영역의 좌표를 구한다.
- 헷갈린 내용 1: `values`가 문자열이어도 `enumerate(values)`를 사용할 수 있는지 헷갈렸다.
- 해결 1: 문자열도 반복 가능한 객체이므로 `enumerate()`를 사용할 수 있다. `j`에는 문자의 인덱스가, `value`에는 해당 문자가 들어간다.

```python
for j, value in enumerate(values):
    if value == '#':
        pass
```

예를 들어 `values = ".#.."`라면 `(0, '.')`, `(1, '#')`, `(2, '.')`, `(3, '.')` 순서로 얻는다.

- 헷갈린 내용 2: 우측 아래 좌표에 왜 `i + 1`, `j + 1`을 저장해야 하는지 몰랐다.
- 원인: 파일이 있는 마지막 칸의 인덱스와 드래그 영역의 끝 경계 좌표를 같은 것으로 생각했다.
- 해결 2: `(i, j)`번 칸은 세로로 `i`부터 `i + 1`, 가로로 `j`부터 `j + 1`까지 차지한다. 따라서 그 칸 전체를 포함하는 우측 아래 경계는 `(i + 1, j + 1)`이다.
- 기억할 규칙: 좌측 위 좌표는 파일의 최소 인덱스이고, 우측 아래 좌표는 파일의 최대 인덱스에 1을 더한 값이다.

```python
answer[0] = min(answer[0], i)
answer[1] = min(answer[1], j)
answer[2] = max(answer[2], i + 1)
answer[3] = max(answer[3], j + 1)
```
