## ❌ 소수 만들기 — 조합의 중복과 합의 중복을 혼동

- 문제: `nums`에서 서로 다른 3개를 골라 더했을 때 소수가 되는 경우의 개수를 구한다.
- 실수: `answer = sorted(set(answer))`로 같은 합을 제거했다.
- 원인: “서로 다른 3개”를 합도 서로 달라야 한다는 뜻으로 이해했다. 실제로는 한 조합 안에서 같은 원소를 다시 고르지 않는다는 뜻이다.
- 해결: 합이 같아도 서로 다른 조합이면 각각 세므로 `set()`을 사용하지 않는다.
- 기억할 규칙: “경우의 개수”와 “서로 다른 결과 값의 개수”를 구분한다. `i < j < k`는 같은 위치 조합의 중복을 막지만 합의 중복까지 막지는 않는다.

예를 들어 `[1, 2, 3, 4, 6]`에서 `1 + 4 + 6`과 `2 + 3 + 6`은 모두 소수 `11`을 만들지만 서로 다른 조합이므로 각각 센다.

### 반복문으로 3개의 합 구하기

```python
def solution(nums):
    answer = []
    result = 0

    for i in range(len(nums) - 2):
        for j in range(i + 1, len(nums) - 1):
            for k in range(j + 1, len(nums)):
                answer.append(nums[i] + nums[j] + nums[k])

    for value in answer:
        is_prime = True
        for divisor in range(2, value):
            if value % divisor == 0:
                is_prime = False
                break
        if is_prime:
            result += 1

    return result
```

### `itertools.combinations` 사용

```python
from itertools import combinations
from math import isqrt


def solution(nums):
    result = 0

    for group in combinations(nums, 3):
        value = sum(group)
        is_prime = True

        for divisor in range(2, isqrt(value) + 1):
            if value % divisor == 0:
                is_prime = False
                break

        if is_prime:
            result += 1

    return result
```

소수가 아닌 수는 약수 쌍 중 하나가 제곱근 이하이므로 제곱근까지만 검사해도 된다. `range()`의 끝은 제외되므로 `isqrt(value) + 1`까지 범위를 잡는다.
