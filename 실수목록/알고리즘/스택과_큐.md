## ❌ 올바른 괄호 — 전체 개수만 비교하고 중간 순서를 확인하지 않음

- 문제: [올바른 괄호](../../파이썬_문제풀이/알고리즘/스택과_큐/올바른_괄호.py) — `(`로 열었으면 반드시 이후의 `)`로 닫히는 올바른 괄호 문자열인지 판별한다.
- 시도한 방법: 딕셔너리로 `(`와 `)`의 전체 개수를 센 뒤, 두 개수가 같고 처음과 마지막 문자가 올바른지 검사했다.
- 실수: 전체 개수와 양 끝만 확인하고 문자열을 왼쪽부터 읽는 중간 상태를 확인하지 않았다.
- 반례: `())(()`는 두 괄호가 각각 3개이고 `(`로 시작해 `)`로 끝나지만, 세 번째 위치에서 닫는 괄호가 먼저 넘치므로 올바르지 않다.
- 추가 문제: 문자열에 한 종류의 괄호만 있으면 존재하지 않는 키를 `counts[')']`처럼 조회할 때 `KeyError`가 발생할 수 있다.

### 카운터 방식

`(`이면 1을 더하고 `)`이면 1을 뺀다. 중간에 음수가 되면 닫을 괄호가 없는데 `)`가 나온 것이므로 바로 실패한다. 끝까지 확인한 뒤 `0`이어야 모든 괄호가 닫힌 것이다.

```python
def solution(s):
    count = 0

    for char in s:
        if char == '(':
            count += 1
        else:
            count -= 1

        if count < 0:
            return False

    return count == 0
```

### 스택과 `pop()` 방식

`(`를 만나면 스택에 넣고, `)`를 만나면 짝이 될 `(`를 `pop()`한다. 스택이 비었는데 `)`가 나오면 올바르지 않다.

```python
def solution_with_stack(s):
    stack = []

    for char in s:
        if char == '(':
            stack.append(char)
        else:
            if not stack:
                return False
            stack.pop()

    return not stack
```

### 어떤 풀이가 더 좋은가?

- 괄호가 `()` 한 종류뿐이면 열린 괄호의 **개수만** 알면 되므로 카운터 방식이 더 간단하다.
- 카운터 방식은 시간 복잡도 `O(n)`, 추가 공간 `O(1)`이다.
- 스택 방식도 시간 복잡도는 `O(n)`이지만 최악의 경우 추가 공간 `O(n)`이 필요하다.
- `()`, `{}`, `[]`처럼 괄호 종류가 여러 개라면 가장 최근에 연 괄호의 종류까지 기억해야 하므로 스택과 `pop()`이 적합하다.

### 여러 괄호를 넣은 버전
```python
def solution(s):
    stack = []

    pairs = {
        ')': '(',
        '}': '{',
        ']': '['
    }

    for char in s:
        # 열린 괄호
        if char in '({[':
            stack.append(char)

        # 닫힌 괄호
        else:
            # 닫을 괄호가 없으면 잘못된 괄호
            if not stack:
                return False

            # 가장 최근에 열린 괄호와 짝이 맞는지 확인
            if stack[-1] != pairs[char]:
                return False

            stack.pop()

    # 열린 괄호가 남아 있으면 False
    return not stack
```

**기억할 규칙:** 올바른 괄호는 전체 개수만 같으면 되는 것이 아니다. 왼쪽부터 확인하는 모든 중간 지점에서 닫는 괄호 수가 열린 괄호 수를 넘으면 안 된다.
