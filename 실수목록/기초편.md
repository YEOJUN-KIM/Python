### ❌ 14 · 문자 코드 값을 개수 배열의 인덱스로 바꾸기

| 구분 | 내용 |
| --- | --- |
| 관련 문제 | 문자 개수 세기 |
| 막힌 부분 | 유니코드 같은 문자 코드 값을 사용해야 할 것 같았지만, 이를 배열의 위치로 바꾸는 방법을 떠올리지 못함 |
| 핵심 | `ord(문자)`로 코드 값을 구하고 기준 문자의 코드 값을 빼면 0부터 시작하는 위치를 얻음 |
| 해결 | 대문자는 `ord(char) - ord('A')`, 소문자는 `ord(char) - ord('a') + 26`을 인덱스로 사용 |

`ord()`는 한 문자의 유니코드 코드 포인트를 정수로 반환한다. 영문 알파벳의 코드 값은 ASCII와 동일하며, 대문자끼리와 소문자끼리는 각각 연속된다.

| 문자 범위 | 코드 값 | 결과 배열의 인덱스 |
| --- | --- | --- |
| `A` ~ `Z` | 65 ~ 90 | 0 ~ 25 |
| `a` ~ `z` | 97 ~ 122 | 26 ~ 51 |

`Z`와 `a` 사이에는 특수문자 6개가 있으므로 모든 문자에서 무조건 `ord('A')`를 빼면 안 된다. 소문자는 `ord('a')`를 빼서 0~25로 만든 뒤, 대문자 26칸 다음에 오도록 `26`을 더한다. 코드 숫자를 외우기보다 기준 문자를 사용한다.

```python
def solution(my_string):
    answer = [0] * 52  # 각 알파벳의 개수를 저장할 52칸

    for char in my_string:
        if 'A' <= char <= 'Z':
            index = ord(char) - ord('A')
        else:  # 입력은 영문 대소문자로만 구성됨
            index = ord(char) - ord('a') + 26

        answer[index] += 1

    return answer
```

예를 들어 `B`는 `66 - 65 = 1`, `b`는 `98 - 97 + 26 = 27`번 칸에 해당한다. `"AAb"`를 세면 `answer[0]`은 `2`, `answer[27]`은 `1`이고 나머지는 `0`이다.

**복습 포인트:** 문자 → 기준 문자와의 차이로 인덱스 계산 → 해당 칸의 개수에 1 더하기. `chr(97)`은 반대로 숫자를 문자 `'a'`로 바꾼다.

### ❌ 15 · 나선형 배열의 이동 조건과 방향 전환

| 구분 | 내용 |
| --- | --- |
| 관련 문제 | [정수를 나선형으로 배치하기](../basic/programmers/기초/정수를_나선형으로_배치하기.py) |
| 원인 1 | 오른쪽·아래 이동 조건을 `j + 1 >= n`, `i + 1 >= n`으로 작성해 배열 밖의 위치를 검사함 |
| 해결 1 | 배열 안으로 이동하려면 `j + 1 < n`, `i + 1 < n`인지 먼저 확인 |
| 원인 2 | 다음 칸을 `!= 0`으로 검사해 이미 채운 칸으로 이동하려 함 |
| 해결 2 | 아직 채우지 않은 칸인 `== 0`인지 확인 |
| 원인 3 | 막혔을 때 방향만 바꾸고 이동하지 않아 다음 반복에서 같은 칸을 덮어씀 |
| 해결 3 | 방향을 바꾼 뒤 새 방향으로 한 칸 이동 |
| 종료 처리 | 마지막 숫자를 넣으면 `break`로 끝내 불필요한 이동을 하지 않음 |

```python
# 오른쪽 이동: 경계를 먼저 검사하고, 그다음 빈칸인지 확인
if j + 1 < n and arr[i][j + 1] == 0:
    j += 1
else:
    mode = 's'
    i += 1  # 아래로 방향을 바꾸면서 이동
```

`and`는 앞 조건이 거짓이면 뒤 조건을 평가하지 않는다. 따라서 경계 검사를 먼저 해야 배열 밖에 접근하지 않는다. 왼쪽·위쪽도 인덱스가 `0` 이상인지 확인한다. Python에서 음수 인덱스는 뒤쪽 원소를 가리키므로 그대로 사용하면 잘못된 칸으로 이동할 수 있다.

**복습 순서:** 현재 칸에 숫자 넣기 → 마지막 숫자면 종료 → 다음 칸의 경계와 빈칸 여부 확인 → 막혔으면 방향 전환 → 이동.

풀이 파일에는 내 `mode`와 `if/elif` 구조를 유지한 수정본을 `my_solution`, 방향별 `(행 변화량, 열 변화량)`과 다음 방향을 딕셔너리로 관리하는 모범 답안을 `best_solution`으로 저장했다.

### ❌ 16 · 이차원 리스트의 행을 만들지 않고 접근

`answer = [[]]`로 시작하고 행을 추가하지 않으면 첫 번째 행만 존재한다. `n >= 2`일 때 `answer[1]`에 접근하면 `IndexError`가 발생한다. `answer = []`로 시작해 바깥 반복문마다 `answer.append([])`로 새 행을 추가한다.
