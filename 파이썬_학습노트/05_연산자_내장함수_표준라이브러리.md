## 내장 함수

| 문법 | 용도 |
| --- | --- |
| `sum(numbers)` | 숫자들의 합계 |
| `sum(numbers) / len(numbers)` | 숫자들의 평균 (`avg()` 기본 함수는 없음) |
| `max(a, b)` / `min(a, b)` | 큰 값 / 작은 값 |
| `zip(a, b)` | 두 자료에서 같은 위치의 값끼리 묶기 |
| `list(map(int, input().split()))` | 공백으로 구분한 입력을 정수 리스트로 변환 |
| `any(조건들)` | 조건 중 하나라도 참이면 `True` |
| `all(조건들)` | 모든 조건이 참이면 `True` |

### `map()`으로 모든 값에 같은 함수 적용하기

`map(함수, 반복할 자료)`는 반복 가능한 자료의 각 값에 같은 함수를 하나씩 적용한다.

```python
numbers = ["3", "4", "5"]
converted = map(int, numbers)

print(list(converted))  # [3, 4, 5]
```

`map(int, numbers)`는 `int("3")`, `int("4")`, `int("5")`를 차례로 실행하는 것과 비슷하다. `map()`의 결과는 리스트가 아닌 `map` 객체이므로, 리스트 형태로 확인하려면 `list()`로 감싼다.

정수의 각 자릿수 합은 정수를 문자열로 바꾸고, 각 문자를 다시 정수로 변환한 뒤 더한다.

```python
number = 34567
result = sum(map(int, str(number)))

print(result)  # 25
```

처리 순서는 `34567` → `"34567"` → `3, 4, 5, 6, 7` → `25`이다. `sum()`은 `map` 객체를 바로 순회할 수 있으므로 합계만 필요하다면 `list()`로 바꿀 필요가 없다.

```python
if not any(char in text for char in "12346789"):
    print("금지된 문자가 하나도 없음")

if all(char in "05" for char in text):
    print("모든 문자가 0 또는 5")
```

## `itertools.combinations`로 조합 구하기

- `from itertools import combinations`로 가져온다.
- `combinations(arr, r)`은 배열에서 순서에 상관없이 `r`개를 고르는 조합을 만든다.
- 각 조합은 튜플이며 `sum(group)`으로 합을 구할 수 있다.
- 같은 위치의 원소를 한 조합 안에서 다시 고르지 않는다.
- 값이 같아도 위치가 다르면 별개로 취급한다.
- 서로 다른 조합의 합이 같아도 경우의 수를 셀 때는 각각 센다.
