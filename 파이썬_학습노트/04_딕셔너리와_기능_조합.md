## 딕셔너리

| 문법 | 용도 |
| --- | --- |
| `data[key]` | 키에 해당하는 값 가져오기 |
| `dict(zip(keys, values))` | 키 목록과 값 목록을 묶어 딕셔너리 생성 |

```python
key = dict(zip(["w", "s", "d", "a"], [1, -1, 10, -10]))
```

## 여러 기능 조합

```python
def solution(n, control):
    key = dict(zip(["w", "s", "d", "a"], [1, -1, 10, -10]))
    return n + sum(key[char] for char in control)
```
