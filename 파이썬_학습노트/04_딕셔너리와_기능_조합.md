## 딕셔너리

| 문법 | 용도 |
|---|---|
| `data = {"a": 1, "b": 2}` | 키와 값을 직접 지정해서 딕셔너리 생성 |
| `dict(zip(keys, values))` | 따로 있는 키 목록과 값 목록을 묶어서 딕셔너리 생성 |
| `data[key]` | 키의 값 가져오기, 키가 없으면 `Error` 발생 |
| `data.get(key)` | 키의 값 가져오기, 키가 없으면 `None` |
| `data.get(key, 0)` | 키의 값 가져오기, 키가 없으면 `0` |
| `data[key] = value` | 새로운 키-값 추가 또는 기존 값 수정 |
| `key in data` | 해당 키가 존재하는지 확인 |
| `key not in data` | 해당 키가 존재하지 않는지 확인 |
| `data.keys()` | 모든 키 가져오기 |
| `data.values()` | 모든 값 가져오기 |
| `data.items()` | 모든 키와 값을 `(key, value)` 형태로 가져오기 |
| `del data[key]` | 해당 키와 값 삭제 |
| `data.pop(key)` | 해당 키의 값을 가져오면서 삭제 |
| `len(data)` | 딕셔너리의 키-값 개수 확인 |


```python
key = dict(zip(["w", "s", "d", "a"], [1, -1, 10, -10]))
```

### 딕셔너리로 문자 개수 세기

문자열에 어떤 문자가 몇 번 나오는지 모두 세려면 문자를 키로, 개수를 값으로 저장한다.

```python
text = "abaababaab"
counts = {}

for char in text:
    if char in counts:
        counts[char] += 1
    else:
        counts[char] = 1

print(counts)       # {'a': 6, 'b': 4}
print(counts['a'])  # 6
print(counts['b'])  # 4
```

### `get()`으로 기본값 사용하기

`dictionary.get(key, default)`는 키가 있으면 저장된 값을, 없으면 지정한 기본값을 반환한다.

```python
counts = {}

for char in text:
    counts[char] = counts.get(char, 0) + 1
```

처음 나온 문자는 `0 + 1`, 이미 나온 문자는 기존 개수에 `1`을 더한다. 없는 키에 `counts[key]`로 직접 접근하면 `KeyError`가 발생하지만 `get()`은 기본값을 사용할 수 있다.

```python
counts = {'b': 4}

counts.get('a', 0)  # 0
# counts['a']       # KeyError
```

찾을 문자가 `a`, `b`처럼 미리 정해져 있고 두 개뿐이라면 `text.count('a')`도 간단하다. 어떤 문자가 나올지 모르고 모든 문자의 개수가 필요하면 딕셔너리가 적합하다.

## 여러 기능 조합

```python
def solution(n, control):
    key = dict(zip(["w", "s", "d", "a"], [1, -1, 10, -10]))
    return n + sum(key[char] for char in control)
```
