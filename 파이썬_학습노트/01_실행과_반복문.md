# 01 · 실행과 반복문

## `if __name__ == "__main__":`

현재 파일을 직접 실행했을 때만 아래 코드를 실행하라는 뜻이다.

```python
if __name__ == "__main__":
    print("이 파일을 직접 실행했습니다.")
```

다른 파일에서 `import`할 때는 이 부분이 실행되지 않으므로 테스트용 코드를 넣을 때 사용한다.

## 기본 순회

| 문법 | 용도 |
| --- | --- |
| `for value in arr:` | 값을 하나씩 순회 |
| `for i in range(len(arr)):` | 인덱스로 순회 |
| `for value in numbers:` | 값을 직접 꺼내 합계나 곱을 누적 |

## `range()`로 범위 정하기

| 문법 | 용도 |
| --- | --- |
| `range(start, end, step)` | `start`부터 `end` 직전까지 `step` 간격으로 순회 |
| `range(start, end, -1)` | 숫자를 1씩 줄이며 역순으로 순회 |

`range()`의 인수는 콜론이 아니라 쉼표로 구분하며, `step`을 생략하면 `1`이다.

## `enumerate()`로 인덱스와 값 함께 순회하기

`enumerate()`에는 리스트뿐 아니라 문자열 같은 반복 가능한 자료도 사용할 수 있다.

```python
arr = ["a", "b", "c"]
for i, value in enumerate(arr):
    print(i, value)

for i, char in enumerate("abc"):
    print(i, char)
```

값만 필요하면 `for value in arr`, 인덱스와 값이 모두 필요하면 `enumerate()`를 사용한다.

## 반복문에서 언패킹하기

각 원소의 값 개수를 알고 있다면 여러 변수로 바로 나눠 받을 수 있다. 값과 변수의 개수는 같아야 한다.

```python
queries = [[0, 3], [1, 2]]

for i, j in queries:
    print(i, j)
```

위 코드는 다음과 같은 의미다.

```python
for query in queries:
    i = query[0]
    j = query[1]
```

## 리스트 컴프리헨션

반복문으로 새로운 리스트를 만드는 코드를 한 줄로 줄이는 문법이다.

```python
answer = []
for value in arr:
    answer.append(value * 2)

answer = [value * 2 for value in arr]
answer = [value for value in arr if value != ""]
```

기본 구조는 `[리스트에 넣을 값 for 변수 in 반복할 자료]`이다. 뒤에 `if`를 붙이면 조건에 맞는 값만 넣는다.
