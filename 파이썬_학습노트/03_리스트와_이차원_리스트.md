## 리스트 기본 기능

- `arr.append(value)` — 리스트 마지막에 값 추가
- `arr.count(value)` — `value`가 등장하는 횟수 반환
- `if not answer:` — 리스트가 비어 있을 때 실행

| 문법 | 용도 |
| --- | --- |
| `stk.append(value)` | 마지막에 값을 추가 |
| `stk.pop()` | 마지막 값을 꺼내면서 삭제 |
| `stk.pop(i)` | `i`번 값을 꺼내면서 삭제 |
| `stk.remove(value)` | 처음 발견되는 `value`를 삭제 |

## 이차원 리스트에 값 추가하기

`arr = [[]]`는 빈 리스트 하나가 들어 있는 리스트다. `arr[0]`은 첫 번째 안쪽 리스트를 가리킨다.

```python
arr = [[]]
arr[0].append(1)
arr[0].append(2)
arr.append([3, 4])
arr[0][1] = 9

print(arr)  # [[1, 9], [3, 4]]
```

`arr = [[]]`에는 안쪽 원소가 없으므로 곧바로 `arr[0][0] = 1`을 하면 `IndexError`가 발생한다. 새 원소는 `append()`, 기존 원소 수정은 인덱스 대입을 사용한다.

## 반복문으로 이차원 리스트 만들기

```python
def solution(n):
    answer = []

    for i in range(n):
        answer.append([])
        for j in range(n):
            if i == j:
                answer[i].append(1)
            else:
                answer[i].append(0)

    return answer
```

- `answer.append([])` — 새 행 추가
- `answer[i].append(값)` — `i`번째 행 안에 값 추가

> 관련 실수: [기초편 · 이차원 리스트의 행을 만들지 않고 접근](../실수목록/기초편.md)

## 이차원 리스트의 특정 위치에서 최댓값 구하기

각 내부 리스트의 `0`번 값, 즉 `sizes[i][0]` 중 가장 큰 값은 다음처럼 구한다.

```python
sizes = [[60, 50], [30, 70], [60, 30], [80, 40]]

max_value = max(size[0] for size in sizes)
print(max_value)  # 80
```

`size[0] for size in sizes`는 `60, 30, 60, 80`을 차례로 꺼내고, `max()`가 그중 가장 큰 `80`을 반환한다.

```python
max_value = sizes[0][0]
for size in sizes:
    if max_value < size[0]:
        max_value = size[0]
```

첫 번째 행의 최댓값은 `max(sizes[0])`, 각 행의 첫 번째 값 중 최댓값은 `max(size[0] for size in sizes)`이다.

## 리스트의 두 값 교환하기

```python
answer[i], answer[j] = answer[j], answer[i]
```

## `copy()`로 리스트 복사하기

`answer = arr`는 복사가 아니라 같은 리스트를 가리키는 대입이다. 변경 전 값을 따로 보관하려면 `arr.copy()`를 사용한다.

```python
arr = [50, 25]
answer = arr.copy()
arr[0] = 25

print(arr)     # [25, 25]
print(answer)  # [50, 25]
```

`copy()`는 얕은 복사이므로 중첩 리스트에서는 내부 리스트까지 복사하지 않는다.

## `set`으로 중복 제거하기

```python
len(set([2, 2, 5]))  # 2
```

`set()`은 중복을 제거하므로 서로 다른 값의 개수를 구할 때 사용할 수 있다.
