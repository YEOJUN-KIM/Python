# 02 · 문자열

[문법 목차](./README.md)

## f-string

문자열 앞에 `f`를 붙이고 `{변수}`로 문자열 안에 변수의 값을 넣는다.

## 순회와 확인

| 문법 | 용도 |
| --- | --- |
| `for char in text:` | 문자를 한 글자씩 순회 |
| `"python" in text` / `"python" not in text` | 문자열 포함 / 미포함 확인 |

## 인덱스와 슬라이싱

| 문법 | 용도 |
| --- | --- |
| `text[-1]` | 마지막 문자 가져오기 |
| `text[:n]` / `text[-n:]` | 앞에서 / 뒤에서 n글자 가져오기 |
| `text[start:end:step]` | `start`부터 `end` 직전까지 `step` 간격으로 슬라이싱 |
| `text[::-1]` | 문자열 전체를 역순으로 뒤집기 |

```python
text[s:e + 1][::-1]  # 인덱스 s부터 e까지 뒤집기
```

> 관련 문제: [`문자열의 뒤의 n글자`](../파이썬_문제풀이/기초_문법/문자열의_뒤의_n글자.py)

## 문자열 변경

| 문법 | 용도 |
| --- | --- |
| `text.upper()` / `text.lower()` | 대문자 / 소문자로 변경 |
| `text.swapcase()` | 대문자와 소문자를 서로 변경 |
| `text.replace("바꿀 값", "새 값")` | 일치하는 값을 모두 변경 |
| `text.translate(str.maketrans({"A": "B", "B": "A"}))` | 여러 문자를 동시에 교체 |

문자열은 원본이 직접 바뀌지 않으므로 결과를 변수에 저장하거나 바로 반환한다. 두 문자를 서로 바꿀 때는 연속 `replace()` 대신 `translate()`를 사용한다.

> 관련 문제: [`rny_string`](../파이썬_문제풀이/기초_문법/rny_string.py), [`문자열 바꿔서 찾기`](../파이썬_문제풀이/기초_문법/문자열_바꿔서_찾기.py)

## 나누기와 연결하기

| 문법 | 용도 |
| --- | --- |
| `text.split()` | 공백을 기준으로 나눠 리스트로 반환 |
| `text.split(",")` | 쉼표를 기준으로 나눠 리스트로 반환 |
| `"".join(words)` / `"-".join(words)` | 문자열들을 붙이기 / `-`로 연결하기 |

## 공백과 특수문자

| 문법 | 용도 |
| --- | --- |
| `text.strip()` / `text.lstrip()` / `text.rstrip()` | 양쪽 / 왼쪽 / 오른쪽 끝 공백 제거 |
| `text.replace(" ", "")` | 문자열의 모든 일반 공백 제거 |
| `\\` / `\"` | 문자열 안에서 역슬래시 / 큰따옴표 출력 |
